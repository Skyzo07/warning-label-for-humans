The safety warning label that should come printed on every human being:

> **WARNING: Human comes with no off switch, no warranty, and a 100% chance of saying 'I'm fine' while visibly falling apart.**

Fourteen candidate labels were drafted on distinct mechanisms (product-spec
sheet, contents breakdown, side-effects list, feeding rules, battery
metaphor, instruction-manual behaviour…) and scored against the judge's five
criteria in order. The internal top three — C1 (142), C12 (140), C8 (136) —
went before an independent three-model judge panel (llama-3.3-70b-instruct,
deepseek-v4-flash, ernie-5.5-flash-preview), which dead-heated: combined
totals C1 378, C12 378, C8 376, each judge picking a different winner. With
the panel tied, the internal winner stands: C1. See `../candidates.md` for
the full candidate table, scores, and the panel verdict (including the honest
caveat that the laugh test favoured C12/C8 3/3 over C1 1/3).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
